# Практикум: из исключений Python в коды статуса gRPC {#lab-python-exceptions-to-grpc-status-codes}

Одиннадцать исключений — пять стандартных, которые библиотека преобразует по умолчанию, три без стандартного соответствия и три доменные ошибки — проходят через сервер gRPC в четырёх конфигурациях: без обработки исключений; со стандартной таблицей соответствий; с добавленными доменными ошибками сервиса; с той же таблицей и фабрикой подробностей, которая возвращает полезное сообщение для доменных ошибок и общее для остальных. Практикум выводит полученные клиентом код статуса и строку подробностей, отмечая строки с утечкой пароля.

```bash
uv venv --python 3.13 .venv
uv pip install --python .venv/bin/python "grpc-server-kit==0.1.1"
.venv/bin/python mapping_lab.py
```
