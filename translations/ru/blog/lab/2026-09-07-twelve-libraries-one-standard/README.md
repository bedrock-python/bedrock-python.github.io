# Практикум: двенадцать библиотек, один стандарт {#lab-twelve-libraries-one-standard}

`generate_and_check.sh` создаёт новую библиотеку из шаблона Copier организации, передавая ответы на все вопросы в командной строке. Затем считает созданные файлы и запускает проверки самого проекта: `uv sync`, `make check`, `make test`. Чтобы использовать локальную копию шаблона, передайте путь к ней первым аргументом.

[Исходный код практикума на GitHub](https://github.com/bedrock-python/bedrock-python.github.io/tree/master/docs/blog/lab/2026-09-07-twelve-libraries-one-standard).
